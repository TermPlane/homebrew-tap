# homebrew-tap

Homebrew formulae, one per package.

```sh
brew install termplane/tap/<formula>
brew info termplane/tap/<formula>
```

The formulae are the files in [`Formula/`](Formula/), one per package. Each
is generated by that package's release and replaced whole by the next one;
none is edited by hand. `brew info` shows what a formula installs, its
version, and any step to run after the install. Upgrades come with
`brew upgrade`.

On Linux, the apt, dnf, zypper and pacman repository at
https://pkg.hackinggate.com installs the same packages.
